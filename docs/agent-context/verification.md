# Verification

모든 코드 또는 콘텐츠 변경 후 아래 루프를 실행한다. 실패하면 원인을 수정하고 처음부터 다시 검증한다.

1. `npm run check` — 타입 오류와 경고가 없어야 한다.
2. `npm run build` — 라우팅, Markdown, 프리렌더 또는 배포에 영향을 주는 변경이면 반드시 실행하며 빌드 오류가 없어야 한다.
3. 새 Markdown 콘텐츠가 있으면 frontmatter의 `title`, `date`와 고유 slug를 확인한다.

## 종료 조건

- 적용 대상인 검증 단계가 모두 통과해야 작업을 완료할 수 있다.
- 동일한 오류가 3회 연속 발생하면 중단하고 사용자에게 원인과 시도한 내용을 보고한다.
- `.svelte-kit/`과 `build/`는 생성 결과물이므로 직접 수정하지 않는다.
